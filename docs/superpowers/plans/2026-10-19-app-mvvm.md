## Review focus

- Old public constructors, getters, function defaults and callable DI factories must remain at the same JVM names; no duplicate Hilt providers or scope drift.
- Environment persisted/selected/effective state must not double-commit or clear the wrong session during cancellation/recreation/retry.
- Session completion must never publish or navigate for an obsolete identity; navigation/restoration must consume exactly once before ending loading.
- Queue/security/splash/foreground platform callbacks must retain cancellation ownership, timing, pass-through failure policy and event order without retaining Activity in ViewModels.
- Campaign lifecycle collection/IO refresh and Firebase token retrieval must preserve the original session capture and avoid duplicate work after rebind.
